# FNB_App_Academy


## FNB PREACADEMY INTRODUCTION TO PYTHON CODING

This repository contains my work completed as part of a **self-paced Introduction to Python Coding course**. The course consists of **six units** designed to introduce the fundamental concepts of Python programming through hands-on exercises and practical challenges.

## Course Overview

Each unit included:

- A lesson covering a core Python concept
- A practical task 
- A challenge 

## Course Outline

### Lesson 1: Introduction to Python
- Introduction to Python and basic syntax
- Practical task: `student_info.py`
- Challenge: `concert_ticket_booker.py`

### Lesson 2: Manipulating Strings
- Working with string data, String methods and formatting
- Practical task: `string_formatter.py`
- Challenge: `password_hint.py`
  
### Lesson 3: Manipulating Numbers
- Numeric data types and Arithmetic operations
- Practical task: `calculator.py`
- Challenge: `fuel_cost_calculator.py`

### Lesson 4: Storage and Access
- Lists and data storage,  Accessing and modifying stored data
- Practical task: `grade_classifier.py`
- Challenge: `atm_sim.py`
  
### Lesson 5: Selection of Tasks
- Conditional statements (`if`, `elif`, `else`) and Decision-making in Python programs
- Practical task: `contact_book.py`
- Challenge: `high_score_tracker.py`

### Lesson 6: Repeating Tasks
- `for` and `while` loops
- Practical task: `grade_report.py`
- Challenge: `phone_search.py`


This course provided a solid foundation in Python programming and prepared me for more advanced topics.
